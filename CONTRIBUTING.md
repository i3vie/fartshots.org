# Contributing to fartshots
Thank you for considering contributing to fartshots.org! This repository is, above all, an experiment.
Most projects will have contributing guidelines outlining exactly what to do, what not to do, what coding style to follow, what features are and
aren't acceptable, and everything else. Fartshots is not one of those projects!
## Rules
1. **Your code must run.**<br>
   If your pull request completely breaks everything, instantly crashes, or prevents deployment otherwise, it'll likely be rejected.
   The deployment pipeline is automatic. Anything that lands in main goes live ASAP (the webhook is set up to pull & restart the server immediately.)
2. **Don't destroy the server.**<br>
   Reasonable CPU, memory, network, etc. are expected. If your contribution turns the host into a space heater, it'll probably be denied.
3. **Nothing illegal.**<br>
   This should be a given. No illegal content, functionality, malware, or anything else to attract lawyers to our humble website.
4. **Respect other people's work.**<br>
   If someone has carved out their own section of the site, leave it alone unless:
   - They explicitly gave you permission to edit it
   - You're fixing a bug
   - The change is collaborative and welcome
   If you make a PR touching someone else's part of the site, the owner of that part will be asked for review as well as the usual required reviews.
   We encourage you to add your own thing! We don't encourage deleting, rewriting or taking over someone else's part of the site.
## What can I contribute?
Anything. Add features, remove features, replace features, redesign the site, add games, add 88x31s, add useless buttons, add useful buttons, add your
middle school art project from 2012, whatever. Everything (within the rules) goes!
## Pull Requests
Open a pull request. It'll be merged with at least 1 approving review from a maintainer, plus an approving review from the code owner if your pull
affects someone else's portion of the website. If your code works, it'll probably be merged - we don't partiuclarly nit your code style.
## Philosophy
Most websites are usually built by a handful of people who know what they want to make. Fartshots is an attempt at figuring out what you get when
a website is built by whoever was sentient enough to press the Fork button.
# Good luck!
